# Pharmacy Management System

A Pharmacy Management System developed to streamline pharmacy operations, including medicine management, inventory tracking, sales, and other essential pharmacy activities.

## Project Structure

```text
├── design/              UML diagrams and system design documentation
├── requirements/        Functional & non-functional requirements, stakeholder analysis
├── screenshots/         Project and Trello screenshots
└── testing/             Test plans and testing results
```

### `/design`

Contains the design documentation and UML diagrams created for the Pharmacy Management System. This includes use case diagrams, class diagrams, sequence diagrams, activity diagrams, and other relevant system design documents.

### `/requirements`

Contains the system requirements documentation, including functional requirements, non-functional requirements, and stakeholder analysis.

### `/screenshots`

Contains screenshots of the Pharmacy Management System and project management activities. This includes system interface screenshots and Trello screenshots showing project planning, task management, and progress.

### `/testing`

Contains the testing documentation and results for the Pharmacy Management System. This includes unit testing, integration testing, system testing, and user acceptance testing. The test documentation includes test cases, inputs, expected results, actual results, and test status.
