# UML Diagrams – Pharmacy Management System

This directory contains the UML diagrams created for the Pharmacy Management System based on its functional requirements.

## Diagrams Included

* **Use Case Diagram** – Shows actors and system functionalities.
* **Class Diagram** – Shows the system's classes and relationships.
* **Sequence Diagrams** – Shows interactions between actors and the system.
* **Activity Diagrams** – Shows workflows and processes.

The diagrams were created using **draw.io**.
