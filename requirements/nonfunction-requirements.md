# Non-Functional Requirements

| ID     | Category        | Requirement                                                                                                                                                                                 |
| ------ | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NFR 1  | Performance     | The system shall display common pages, such as the medicine search and inventory pages, within three seconds under normal operating conditions.                                             |
| NFR 2  | Security        | User credentials and sensitive pharmacy information shall be protected from unauthorized access, and each staff member shall use individual login credentials.                              |
| NFR 3  | Usability       | A pharmacy staff member with basic computer skills shall be able to perform the system's core tasks after a short period of basic training.                                                 |
| NFR 4  | Availability    | The system shall be available at least 99% of the pharmacy's normal operating hours, excluding planned maintenance.                                                                         |
| NFR 5  | Reliability     | Pharmacy data shall be backed up automatically at least once per day to reduce the risk of data loss.                                                                                       |
| NFR 6  | Scalability     | The system shall support at least 2,000 medicine, customer, prescription, and transaction records without a noticeable decrease in normal performance.                                      |
| NFR 7  | Data Integrity  | The system shall validate required information and maintain accurate medicine quantities after inventory and sales transactions.                                                            |
| NFR 8  | Maintainability | The system shall use a clear and organized structure so that authorized developers can modify or maintain individual system components without unnecessary changes to unrelated components. |
| NFR 9  | Privacy         | Customer and prescription information shall only be accessible to users with appropriate permissions.                                                                                       |
| NFR 10 | Compatibility   | If implemented as a web-based system, the system shall function correctly on commonly used modern web browsers and standard desktop or laptop screen sizes.                                 |
