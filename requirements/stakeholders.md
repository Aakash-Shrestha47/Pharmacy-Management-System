# Stakeholders

| **Stakeholder**                 | **Role / Responsibilities**                                                                              |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- | 
| **Pharmacy Administrator**      | Manages staff accounts, user roles, and access permissions.                                              |
| **Pharmacy Manager**            | Manages suppliers and monitors inventory, sales, and pharmacy operations.                                |
| **Pharmacist**                  | Manages medicine records, inventory information, and customer prescriptions.                             | 
| **Cashier**                     | Processes medicine sales, calculates totals, generates bills, and updates inventory.                     | 
| **Customer**                    | Purchases medicines and provides prescription information when required.                                 | 
| **Supplier**                    | Supplies medicines to the pharmacy and is associated with supplier records.                              | 
| **System Developer/Maintainer** | Maintains the system and ensures its performance, security, reliability, scalability, and compatibility. |
