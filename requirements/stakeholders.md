# Stakeholders

| **Stakeholder**                 | **Role / Responsibilities**                                                                              | **Main Requirements**                            |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **Pharmacy Administrator**      | Manages staff accounts, user roles, and access permissions.                                              | FR 1, FR 11, FR 12, NFR 2                        |
| **Pharmacy Manager**            | Manages suppliers and monitors inventory, sales, and pharmacy operations.                                | FR 3, FR 4, FR 9, FR 10                          |
| **Pharmacist**                  | Manages medicine records, inventory information, and customer prescriptions.                             | FR 2, FR 3, FR 4, FR 5, FR 6                     |
| **Cashier**                     | Processes medicine sales, calculates totals, generates bills, and updates inventory.                     | FR 5, FR 7, FR 8                                 |
| **Customer**                    | Purchases medicines and provides prescription information when required.                                 | FR 6, FR 7, FR 8, NFR 9                          |
| **Supplier**                    | Supplies medicines to the pharmacy and is associated with supplier records.                              | FR 2, FR 9                                       |
| **System Developer/Maintainer** | Maintains the system and ensures its performance, security, reliability, scalability, and compatibility. | NFR 1, NFR 2, NFR 4, NFR 5, NFR 6, NFR 8, NFR 10 |
